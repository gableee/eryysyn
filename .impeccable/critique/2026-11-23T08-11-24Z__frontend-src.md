## Anti-Patterns Verdict

LLM: not AI slop. No gradient text, glass, side stripes, eyebrows, card grids. Login card-in-card fixed. Mild tells left: source = panel > bordered card > tinted excerpt box (3 nested containers); the selected card's 3px glow reads like keyboard focus.
Detector: CLI 0 findings (frontend/src). Browser overlay on chat/library/new chat/login at 1440 and 390: single-font and flat-type-hierarchy on every page = false positives (one family and a tight scale are deliberate in a product UI); text-overflow on the hidden new-chat header = false positive (screen-reader-only header keeps its side padding; set padding 0 to silence).

## Priority Issues

1. [P1] Sources panel not tied to an answer: panel says only "Sources"; after a refusal it shows an older answer's sources beside "Not found in your documents." Fix: title it with the question ("Sources for: ..."), say "From your earlier question" when the newest answer is a refusal, mark the selected answer. (/impeccable clarify, layout)
2. [P1] Evidence stops short of the page (carried over): whole chunk in a scroll box, cited sentence not highlighted (--hl unused), "p. 112" opens nothing. Fix: highlight best-matching sentence, start there, "Show whole passage"; "Open page 112" link to the stored PDF (#page=112). Needs backend signed URL. (/impeccable shape)
3. [P2] Phone navigation loses your place: Chat tab -> blank new chat; Recent only in drawer beside tabs. Fix: tab returns to last chat, or a "Chats" tab with Recent + New chat. (/impeccable adapt)
4. [P2] Library: bold "Delete" on every row, rows lead nowhere, confirm doesn't warn about "Source removed". Fix: muted trash icon button (label kept), consequence line in confirm, later "Ask about it" / open PDF. (/impeccable quieter, polish)
5. [P2] Login: no "Forgot password?", no "or" divider, Google error not styled. Fix: reset link (Supabase resetPasswordForEmail + set-new-password page), "or" rule, error class. (/impeccable harden)
