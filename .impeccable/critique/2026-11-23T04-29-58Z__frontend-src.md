## Anti-Patterns Verdict
Not AI slop: restrained Sage, one accent, no eyebrows, no side stripes, real content. Detector CLI on frontend/src: 0 findings (mockup: 2). Browser: line length ~89ch on chat (real, small); single font + flat type scale (product register: deliberate, false positive); login: thin border + 32px shadow and card-in-card on the preview window (real).

## Priority Issues
- [P0] Phone: in a chat with messages the composer (y 790-831) is under the bottom tab bar (y 787-844); the tab bar is the top element, so the box cannot be tapped. Both are sticky bottom:0. Fix: offset the composer dock by the tab bar height + safe area below 600px (0 when tabs are hidden). Command: /impeccable adapt.
- [P1] The evidence is buried: each source shows the whole ~250-token chunk in a small scroll box; the cited sentence is often below the fold, and on phone it is a scroll inside the page scroll. Fix: highlight the best-matching sentence, show it with context, "Show whole passage" (owner deferred this; still the biggest product gap). Command: /impeccable shape.
- [P2] Login preview: thin border + wide shadow and a card inside a card. Fix: drop the window chrome, let the example sit directly on the side panel. Command: /impeccable quieter.
- [P2] Answer lines ~89 characters. Fix: cap the answer at ~60ch. Command: /impeccable typeset.
- [P2] Robustness: never send without a workspace id (data-layer guard, not only a disabled control); refresh the chat title right after the first answer; when the newest answer is a refusal, keep the previous sources reachable. Command: /impeccable harden.
